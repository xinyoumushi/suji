速记 · 个人备考记忆知识库（便携版）
=====================================

【第一次：怎么解除「对计算机有害」的提示】

  这是 Windows 的 SmartScreen 拦截：压缩包从网上下载后会被打上「来自其他计算机」的标记，
  解压出来的程序又没有数字签名，所以第一次运行会被拦。不是病毒，处理办法有三档：

  ① 最省事（推荐）：解压之前先解除锁定
     右键点这个压缩包 → 属性 → 勾选底部的「解除锁定」→ 确定 → 再解压。
     这样解压出来的文件就是「干净」的，后面不会再弹任何提示。

  ② 已经解压了：直接双击「启动速记.bat」
     启动器第一次运行会自动把文件夹里的程序标记清掉，
     所以可能只弹一次，之后正常。若弹窗是蓝色的「Windows 已保护你的电脑」，
     点「更多信息」→「仍要运行」即可。

  ③ 想彻底不再提示：需要购买代码签名证书给程序签名（个人使用没必要）。

  其它兜底：如果 Windows Defender 报毒，把这个文件夹加入「排除项」即可
  （设置 → 隐私和安全性 → Windows 安全中心 → 病毒和威胁防护 → 管理设置 → 排除项）。

【怎么启动】

  解压后双击「启动速记.bat」。
  第一次启动会自动在桌面创建一个「速记」快捷方式，
  以后直接双击桌面的「速记」图标就行。

  · 任务栏里还会有一个叫「速记服务」的最小化窗口，
    关掉它才是真正退出程序（只关界面窗口不算退出）。
  · 重复双击不会开第二个，会直接复用已经在跑的那个。

【数据在哪】

  默认放在：%APPDATA%\速记\data\suji.db
  如果这个位置不可写，会自动放在本文件夹的 data\ 目录下。
  启动后点界面右下角「数据目录」就能看到实际位置。

  · 所有数据只存在这台电脑上，不联网、不上传。
  · 每天第一次启动、导入前、批量删除前会自动生成数据库快照，
    保存在同级的 backups\ 目录，最多保留 10 份。

【怎么备份 / 换电脑】

  界面里「导入导出」→「导出 JSON 备份」，把生成的 .json 文件保存好；
  在新电脑上装好本程序，「批量导入 / 还原备份」选择这个 JSON 即可完整还原
  （目录层级、文件夹备注、卡片内容、标签、多引用关系、画重点的高亮都会保留）。

【导入模板】

  本文件夹里的「导入模板.xlsx」是配套模板，
  也可以在界面里「导入导出 → 下载模板」重新下载一份。

【打不开怎么办】

  1. 确认本文件夹完整：runtime\node.exe 和 out\server\index.cjs 都在；
  2. 提示端口被占用时，先关掉任务栏里多余的「速记服务」窗口再试；
  3. 还不行就看 data\server-error.log 里的错误信息。

【系统要求】

  Windows 10 / 11 64 位，自带 Microsoft Edge（Win10/11 默认都有）。
  界面是用 Edge 的应用窗口打开的，所以没有地址栏，这是正常的。
